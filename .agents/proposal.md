# 타키온(Tachyon) UI 그리드 컴포넌트 기능 가이드 및 화면 기획서

> **Tachyon DataGrid & TreeGrid**  
> 대용량 데이터 처리와 캔버스 기반 고속 렌더링, 유연한 상호작용을 제공하는 엔터프라이즈 UI 그리드 컴포넌트 라이브러리입니다.

---

## 1. 컴포넌트 개요

* **DataGrid**: 대규모 정형 데이터를 표 형태로 고속 렌더링하고, 멀티헤더·4방향 틀고정·인라인 편집을 제공하는 기본 그리드 컴포넌트입니다.
* **TreeGrid**: 부모-자식 계층 구조(BOM, 조직도, WBS 등)를 표현하며, 노드 접기/펼치기 및 계층별 인덴트를 지원하는 계층 특화 그리드 컴포넌트입니다.

---

## 2. 그리드 핵심 특징 (Core Features)

* 🚀 **대용량 가상 스크롤 (High-Performance Virtual Scrolling)**
  * 화면에 보이는 뷰포트(Viewport) 영역만 즉각 계산하여 렌더링하는 가상화 기술을 적용합니다.
  * 데이터 건수가 대규모로 늘어나도 브라우저 메모리 부하를 최소화하며, 끊김이나 지연 없는 부드러운 스크롤을 제공합니다.

* 📊 **셀 내 데이터 시각화 (In-Cell Visualization)**
  * HTML5 Canvas 2D 기반의 커스텀 렌더러를 활용하여 셀 내부에 미니 차트와 시각 요소를 직접 렌더링합니다.
  * 별도의 무거운 DOM 엘리먼트 생성 없이 12개월 추세선(스파크라인), 목표 달성률 진행 바, 히트맵, 상태 배지를 셀 안에서 가볍고 빠르게 표현하여 한눈에 현황을 파악할 수 있습니다.

* ⌨️ **스프레드시트형 키보드 및 다중 조작 (Keyboard & Range Interaction)**
  * 엑셀과 동일한 직관적인 조작 방식으로 실무 작업의 피로도를 낮춥니다.
  * 방향키와 Tab/Enter 키를 통한 빠른 셀 이동, 마우스 드래그 다중 영역 선택, 클립보드 복사 및 붙여넣기(`Ctrl+C / Ctrl+V`), 더블클릭 인라인 셀 수정을 완벽하게 지원합니다.

* 📐 **멀티헤더 및 4방향 틀고정 (Multi-Level Headers & Pinning)**
  * 2단 이상의 멀티헤더로 방대한 업무 항목을 논리적인 그룹으로 체계화합니다.
  * 상·하단 요약행과 좌·우 기준 식별/상태 열을 동시에 고정하여 스크롤 중에도 데이터 기준을 명확하게 유지합니다.

* 🌳 **계층형 트리 그리드 (Hierarchical Tree Structure)**
  * 부모-자식 노드로 구성된 다단계 계층 데이터를 시각적으로 구조화합니다.
  * 단계별 노드 펼치기/접기(Expand/Collapse)와 자동 들여쓰기를 지원하여 부품 품목표(BOM), 조직도, 계층형 WBS 데이터를 직관적으로 탐색합니다.

* 🎨 **사용자 맞춤형 렌더링 (Custom Cell & Header Rendering)**
  * 정형화된 표 형태를 넘어 업무 화면 목적에 맞춘 자유로운 디자인을 제공합니다.
  * 진행상태 배지, 조작용 액션 버튼, 통화 및 날짜 서식 포맷터를 유연하게 결합하여 기업 고유의 업무 프로세스에 최적화된 화면을 구성할 수 있습니다.

* 🔍 **통합 데이터 필터 및 다중 열 정렬 (Integrated Filter & Multi-Sort)**
  * 텍스트 검색, 숫자 범위, 날짜 피커, 체크박스 필터와 Shift 클릭 기반의 다중 열 순차 정렬을 지원합니다.
  * 수많은 행 속에서 담당자가 원하는 조건의 데이터를 오차 없이 신속하게 필터링하고 정렬하여 업무 처리 속도를 높입니다.

* 🖥️ **고해상도 정밀 디스플레이 (HiDPI Sharp Display)**
  * 디스플레이 화면 배율을 감지하여 캔버스 스케일을 보정합니다.
  * Retina 및 4K 이상의 고해상도 모니터 환경에서도 텍스트 번짐 없이 1px 그리드 구분선이 선명하고 또렷하게 표시됩니다.

* 📁 **서식 유지 엑셀 내보내기 (Spreadsheet Export)**
  * 다단 그룹 헤더 구조, 통화 및 숫자 서식, 정렬된 순서를 그대로 보존하여 스프레드시트(XLSX) 파일로 다운로드합니다.
  * 백그라운드 웹 워커(Web Worker) 방식을 채택하여 대용량 데이터를 내려받는 중에도 화면 멈춤 없이 원활히 동작합니다.

## 3. 그리드 상세 기능 목록

### ① 컬럼(열) 제어
* **멀티헤더**: 2단 이상의 컬럼 그룹화 구성
* **좌·우 열 고정 (틀고정)**: 주요 식별자 열(좌측) 및 상태/관리 열(우측) 고정, 1px 구분선 적용
* **열 너비 제어**: 콘텐츠 기반 자동 너비 계산(Auto-fit), 헤더 드래그를 통한 너비 조절
* **열 순서 및 표시 제어**: 컬럼 드래그 순서 변경, 컬럼 동적 표시/숨김
* **컬럼 필터**: 텍스트, 숫자 범위, 날짜 선택, 체크리스트(Set) 필터

### ② 행(줄) 및 가상화 제어
* **대용량 가상 렌더링**: 50만 건 데이터 뷰포트 기반 고속 가상 스크롤
* **상·하 행 고정 (틀고정)**: 상단 긴급 기준 데이터 고정, 하단 총 결산/집계 요약행 고정
* **행 높이 제어**: 고정 행 높이 및 셀 내용에 맞춘 자동 행 높이 계산
* **실시간 데이터 동기화**: 행 추가/삭제/값 변경 시 변경 셀만 국소 재렌더링

### ③ 셀 렌더러 및 시각화
* **커스텀 셀 렌더러**: 상태 뱃지, 아이콘, 버튼 렌더링
* **인셀 차트 위젯**: 꺾은선 스파크라인, 목표 달성률 진행 바, 위험도 히트맵
* **데이터 서식(Format)**: 숫자 천단위 콤마, 통화 표기, 백분율, 날짜/시간 포맷터 자동 적용
* **빈 값 처리**: 결측치 대체 텍스트(`-`) 표기

### ④ 편집 및 데이터 조작
* **인라인 셀 편집**: 텍스트, 숫자 스피너, 드롭다운 셀렉트, 날짜 피커 에디터
* **범위 선택**: 마우스 드래그를 통한 직사각형 다중 셀 블록 선택
* **클립보드 연동**: 선택 영역 `Ctrl+C` 복사, 외부 스프레드시트 데이터 `Ctrl+V` 붙여넣기
* **파일 내보내기**: 그리드 서식 및 멀티헤더가 유지된 XLSX 파일 다운로드

### ⑤ 정렬 및 계층 트리
* **다중 열 정렬**: 헤더 클릭 단일 정렬 및 Shift + 클릭 다중 컬럼 순차 정렬
* **트리 노드 제어**: 단계별 노드 접기/펼치기, 전체 노드 일괄 토글
* **계층 데이터 탐색**: 상위 노드 접힘 상태에서도 하위 데이터 무결성 유지

## 5. 제안서 및 슬라이드 활용 가이드

* **고객 보고용 핵심 메시지**:
  1. **고속 가상화 성능**: 대규모 정형 데이터셋에서도 브라우저 부하 없이 지연 없는 가상 스크롤로 원활한 구동
  2. **업무 생산성**: 상·하·좌·우 4방향 틀고정과 엑셀 호환 키보드/클립보드 조작으로 실무 피로도 최소화
  3. **시각적 인사이트**: Canvas 2D 기반 인셀 미니 차트와 히트맵으로 별도 팝업 없이 즉각적인 데이터 파악
  4. **엔터프라이즈 완성도**: 1px 초정밀 선명도와 다중 테마(라이트/다크/스틸블루)로 고급 업무 환경 구축
