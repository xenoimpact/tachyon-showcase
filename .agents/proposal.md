# 타키온(Tachyon) UI 그리드 컴포넌트 소개 및 기능 가이드

> **Tachyon - 대용량 데이터 처리와 직관적인 상호작용을 지원하는 고성능 UI 그리드 컴포넌트**
> 
> 빠르고 안정적인 엔터프라이즈 데이터 처리, 이제 Tachyon과 함께!  
> Tachyon은 대규모 웹 애플리케이션을 위한 고성능 UI 그리드 컴포넌트 라이브러리입니다. Canvas 기반 가상 스크롤 렌더링, 인셀(In-cell) 시각화, 키보드 중심의 빠른 데이터 조작 등 강력한 기능을 통해 대용량 데이터 조회와 분석 환경을 극대화합니다.

---

## 1. Tachyon 이란?

> **tachyon.js**는 자바스크립트 기반의 고성능 대용량 데이터 처리 UI 그리드 컴포넌트입니다.  
> 대용량 데이터를 지원하는 가상 스크롤과 Canvas-DOM 하이브리드 기술을 통해 수만~수십만 건의 데이터도 지연 없이 부드럽게 표현하며, 단순 표 조회부터 복잡한 계층 구조 및 인라인 셀 수정까지 다양한 업무 요구사항에 유연하게 대응합니다.  
> 제공되는 주요 컴포넌트로는 표 형태의 데이터를 다루는 `DataGrid`와 계층형 트리 데이터를 다루는 `TreeGrid` 등이 있습니다.

---

## 2. Features (주요 특징)

* 🚀 **High-Performance Virtual Scrolling (대용량 가상 스크롤)**
  > 대용량 데이터를 지원하는 가상 스크롤 기술로, 데이터 건수가 많아져도 끊김이나 지연 없는 부드러운 스크롤을 제공합니다.

* 📊 **In-Cell Visualization (셀 내 데이터 시각화)**
  > 셀 안에 미니 차트(스파크라인), 막대 그래프, 진행률 바, 게이지, 상태 배지 등을 직접 렌더링하여 단순 수치 표를 직관적인 대시보드로 확장합니다.

* ⌨️ **Keyboard & Range Interaction (키보드 및 다중 조작)**
  > 방향키와 Tab 키를 통한 빠른 셀 이동, 마우스 드래그 다중 영역 선택, 클립보드 복사 및 붙여넣기(`Ctrl+C / Ctrl+V`), 인라인 셀 수정을 완벽히 지원합니다.

* 📐 **Multi-Level Headers & Pinning (다단 헤더 및 틀 고정)**
  > 2단 이상의 계층형 그룹 헤더를 지원하며, 좌·우 열 고정과 상·하단 요약 행 고정을 통해 복잡한 기준정보도 체계적으로 정렬합니다.

* 🌳 **Hierarchical Structure (계층형 트리 그리드)**
  > 부모-자식 노드 간 탐색과 단계별 펼치기/접기(Expand/Collapse)를 지원하여 조직도, 품목 분류, 프로젝트 WBS 등을 직관적으로 관리합니다.

* 🎨 **Custom Cell & Header Rendering (사용자 맞춤 렌더링)**
  > 셀과 헤더의 형태를 제한 없이 커스터마이징할 수 있어 배지, 아이콘, 버튼 등 화면 목적에 맞게 자유롭게 디자인할 수 있습니다.

* 🔍 **Filtering & Multi-Column Sorting (정합 정렬 및 필터)**
  > 텍스트, 숫자, 날짜, 목록 선택 필터와 함께 단일 및 다중 열 정렬 기능을 통해 방대한 데이터 속에서 원하는 항목을 신속하게 탐색합니다.

* 🖥️ **HiDPI Sharp Display (고해상도 선명도 지원)**
  > 모니터의 화면 배율을 감지하여 고해상도(HiDPI/Retina) 환경에서도 텍스트와 테두리가 번짐 없이 선명하게 표시됩니다.

* 📁 **Spreadsheet Export (XLSX 내보내기)**
  > 다단 헤더 구조와 데이터 서식을 그대로 유지한 채 스프레드시트(XLSX) 파일로 간편하게 내보낼 수 있습니다.

## 3. Components (컴포넌트 구성)

### 1) DataGrid
대규모 정형 데이터를 표 형태로 표시하고 관리하는 고성능 그리드 컴포넌트입니다.
* **가상 스크롤**: 수만~수십만 건의 데이터도 화면 영역만 실시간 렌더링
* **다단 헤더 및 열 제어**: 그룹 헤더, 좌우 열 고정, 열 너비 자동 계산 및 드래그 조절, 열 순서 변경
* **연속 데이터 조작**: 방향키 이동, 범위 선택, 클립보드 복사/붙여넣기, 빠른 인라인 셀 편집
* **셀 시각화**: 차트(스파크라인/막대), 진행률 바, 히트맵, 상태 배지 지원
* **데이터 탐색**: 헤더 클릭 정렬, 다중 열 정렬, 컬럼별 맞춤 필터

### 2) TreeGrid
부모-자식 관계를 가지는 계층형 데이터를 표현하는 계층 특화 그리드 컴포넌트입니다.
* **노드 탐색 및 제어**: 단계별 노드 펼치기/접기, 계층 구조 자동 인덴트
* **DataGrid 기능 상속**: 가상 스크롤, 다단 헤더, 열 고정, 셀 시각화 및 편집 기능 100% 동일 제공
* **업무 적용**: 품목 분류체계(BOM), 부서 조직도, 계정 과목표 등 다단계 계층 데이터 표현 최적화

## 4. 기능 상세 리스트

### ① 컬럼(열)
* 다단 헤더: 2단 이상의 계층형 그룹 헤더
* 좌·우 열 고정 (틀 고정)
* 열 너비 자동 계산: 최소/최대 너비와 남는 공간을 기준으로 배분
* 열 너비 조절: 헤더 경계선을 마우스로 드래그
* 열 순서 변경: 헤더 드래그 (계층 헤더는 같은 부모 안에서만 이동)
* 열 표시/숨김, 열 동적 추가/삭제
* 열 필터: 텍스트, 숫자, 날짜, 목록 선택(Set), 함수 기반 사용자 정의 필터

### ② 행(줄)과 데이터
* 대용량 데이터 표시: 대용량 데이터를 안정적으로 지원하는 가상 스크롤
* 상·하 행 고정: 상단 기준 행, 하단 합계/요약 행
* 행 높이 지정 및 자동 조절(내용 길이에 맞춤)
* 표시 행 개수 지정
* 데이터 추가/삭제/수정 시 화면 자동 반영
* 데이터가 바뀌면 변경된 셀만 다시 그림

### ③ 셀과 헤더 커스텀 렌더러, 편집
* **셀 커스텀 렌더러**: DOM 템플릿 방식 또는 Canvas 직접 그리기 방식 중 선택
* **헤더 커스텀 렌더러**: 헤더에 체크박스, 아이콘, 버튼 등을 표시
* **셀 안에 표시할 수 있는 시각화 예시**
  * 막대 차트, 꺾은선(스파크라인) 차트
  * 진행률 바, 게이지
  * 값에 따라 색이 바뀌는 히트맵 셀
  * 상태 배지, 아이콘
* **셀 안에서 바로 수정**: 더블클릭, F2 키, 직접 타이핑으로 인라인 편집 시작
* 입력 방식: 텍스트, 목록 선택, 날짜 선택, 체크박스 등
* 표시 형식 지정: 숫자 콤마, 날짜 형식 등
* 빈 값 표시 방식 지정
* 화면 밖으로 나간 셀 요소를 재사용하는 구조

### ④ 데이터 조작 및 클립보드 연동
* 마우스 드래그로 셀 다중 영역 선택
* 키보드 이동: 방향키, Tab, PageUp/PageDown, Home, End
* 복사: 선택한 셀을 클립보드로 복사 (`Ctrl+C`)
* 붙여넣기: 외부 스프레드시트나 표에서 복사한 다중 행·열 데이터를 붙여넣기 (`Ctrl+V`)
* 스프레드시트(XLSX) 파일로 내보내기: 다단 헤더 구조 반영

### ⑤ 정렬
* 헤더 클릭으로 오름차순 → 내림차순 → 해제 순환
* 다중 열 정렬: Shift 키를 이용해 여러 열을 순차 지정
* 사용자 정의 정렬: 비교 함수로 정렬 순서 지정

### ⑥ 계층 뷰(TreeGrid)
* 부모-자식 계층 표현, 펼치기/접기
* 다단 헤더, 열 고정, 정렬, 셀 편집 등 DataGrid 기능 동일 사용 가능

## 5. 슬라이드 제작용 요약

**[슬라이드 1] 대용량 데이터를 지원하는 가상 스크롤**
* 대용량 데이터도 지연이나 버벅임 없이 부드럽게 스크롤
* 데이터 건수가 늘어도 안정적인 렌더링 성능 유지
* 데이터가 바뀌면 해당 셀만 갱신

**[슬라이드 2] 다단 헤더와 틀고정**
* 2단 이상의 그룹 헤더
* 좌·우 열 고정, 상·하 행 고정
* 열 너비 자동 계산, 마우스로 너비 조절

**[슬라이드 3] 트리 그리드**
* 계층형 데이터를 펼치고 접기
* 트리 안에서도 정렬, 열 고정, 셀 편집 사용

**[슬라이드 4] 키보드 중심의 빠른 데이터 조작**
* 마우스 드래그 영역 선택, 키보드 방향키 이동
* 셀 더블클릭이나 F2로 바로 수정
* 클립보드 다중 행·열 데이터 붙여넣기, 스프레드시트(XLSX) 파일 내보내기

**[슬라이드 5] 셀 안의 차트와 시각화**
* 스파크라인, 막대, 진행률, 게이지, 히트맵을 셀 안에 직접 표시
* 헤더와 셀을 원하는 모양으로 직접 구성
* 차트가 들어간 열도 정렬과 필터 사용

**[슬라이드 6] 선명한 화면 표시**
* 고해상도(HiDPI) 모니터에서도 글자와 테두리가 선명
* 빈 값 표시 방식 지정

**[슬라이드 7] 정렬과 필터**
* 헤더 클릭 정렬, 다중 열 정렬
* 텍스트, 숫자, 날짜, 목록 선택, 사용자 정의 필터

## 6. 추천 화면 캡처 목록

1. **기본 그리드**: 2단 헤더, 좌측 열 고정, 상태 배지
2. **트리 그리드**: 상위 항목 아래로 하위 항목이 펼쳐진 화면
3. **영역 선택과 셀 수정**: 드래그로 선택된 셀 영역, 날짜/목록 에디터가 열린 화면
4. **정렬과 필터**: 정렬 표시, 필터 팝업
5. **셀 시각화**: 스파크라인, 막대와 진행률, 게이지, 히트맵 셀, 커스텀 헤더를 한 표에 표시
6. **성능 시연**: 데이터 건수 선택(1만/10만/100만), 현재 건수, 실제로 화면에 그려진 셀 수, 로드·첫 렌더링 시간 표시, 실시간 갱신 모드
