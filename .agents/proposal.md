# 타키온(Tachyon) UI 그리드 컴포넌트 기능 가이드 및 화면 기획서

> **Tachyon DataGrid & TreeGrid**  
> 대용량 데이터 처리와 캔버스 기반 고속 렌더링, 유연한 상호작용을 제공하는 엔터프라이즈 UI 그리드 컴포넌트 라이브러리입니다.

---

## 1. 컴포넌트 개요

* **DataGrid**: 대규모 정형 데이터를 표 형태로 고속 렌더링하고, 다단 헤더·4방향 틀고정·인라인 편집을 제공하는 기본 그리드 컴포넌트입니다.
* **TreeGrid**: 부모-자식 계층 구조(BOM, 조직도, WBS 등)를 표현하며, 노드 접기/펼치기 및 계층별 인덴트를 지원하는 계층 특화 그리드 컴포넌트입니다.

---

## 2. 그리드 핵심 특징 (Core Features)

* 🚀 **대용량 가상 스크롤 (Virtual Scrolling)**
  * 100만 건 이상의 방대한 데이터도 브라우저 뷰포트 영역만 계산하여 즉각 렌더링합니다.
  * 데이터 건수가 증가해도 메모리 점유율을 일정하게 유지하며 60fps의 부드러운 스크롤을 제공합니다.

* 📐 **실무 4방향 동시 틀고정 (4-Way Pinning)**
  * 상단 긴급 행, 하단 합계 요약행, 좌측 식별 열, 우측 상태 열을 동시에 고정할 수 있습니다.
  * 1px 정밀 구분선 표준화를 통해 시각적 안정성과 가독성을 보장합니다.

* 🏢 **다단 계층 그룹 헤더 (Multi-Level Headers)**
  * 2단 이상의 복합 계층 헤더를 자유롭게 구성하여 복잡한 비즈니스 기준정보를 그룹화합니다.
  * 헤더 드래그를 통한 열 너비 조절 및 부모 그룹 내 순서 변경을 지원합니다.

* ⌨️ **인라인 편집 및 키보드 조작 (Inline Editing & Keyboard Nav)**
  * 셀 더블클릭, F2 키, 직접 타이핑을 통해 즉시 인라인 수정 모드로 진입합니다.
  * 방향키, Tab, PageUp/Down, Home, End 키로 연속 셀 이동 및 데이터 탐색이 가능합니다.

* 📋 **클립보드 및 엑셀(XLSX) 연동 (Clipboard & Spreadsheet)**
  * 마우스 드래그를 통한 다중 셀 영역 선택 및 `Ctrl+C / Ctrl+V` 클립보드 복사·붙여넣기를 완벽히 지원합니다.
  * 다단 헤더와 서식이 반영된 상태로 대용량 데이터를 엑셀(XLSX) 파일로 즉시 내보냅니다.

* 📊 **인셀 시각화 렌더링 (In-Cell Visualization)**
  * 셀 내부에 12개월 추세 스파크라인 차트, 진행률 바, 게이지, 히트맵, 상태 배지를 직접 렌더링합니다.
  * 복잡한 수치 데이터를 직관적인 시각 정보로 표현하여 화면 활용도를 극대화합니다.

* 🌳 **계층형 트리 데이터 지원 (Hierarchical Tree Structure)**
  * 부모-자식 노드 간 단계별 접기/펼치기(Expand/Collapse) 및 자동 들여쓰기를 지원합니다.
  * DataGrid의 가상 스크롤, 열 고정, 셀 편집 기능을 계층 트리에서도 100% 동일하게 활용합니다.

* 🎨 **HiDPI 선명도 및 다중 테마 (Sharp Display & Themes)**
  * 화면 배율을 감지하여 고해상도 모니터에서도 텍스트와 1px 보더가 번짐 없이 선명하게 표시됩니다.
  * 기본 화이트, 다크, 스틸 블루 등 업무 환경에 맞춘 엔터프라이즈 테마를 즉시 전환할 수 있습니다.

## 3. 그리드 상세 기능 목록

### ① 컬럼(열) 제어
* **다단 계층 헤더**: 2단 이상의 컬럼 그룹화 구성
* **좌·우 열 고정 (틀고정)**: 주요 식별자 열(좌측) 및 상태/관리 열(우측) 고정, 1px 구분선 적용
* **열 너비 제어**: 콘텐츠 기반 자동 너비 계산(Auto-fit), 헤더 드래그를 통한 너비 조절
* **열 순서 및 표시 제어**: 컬럼 드래그 순서 변경, 컬럼 동적 표시/숨김
* **컬럼 필터**: 텍스트, 숫자 범위, 날짜 선택, 체크리스트(Set) 필터

### ② 행(줄) 및 가상화 제어
* **대용량 가상 렌더링**: 100만 건 데이터 뷰포트 기반 고속 가상 스크롤
* **상·하 행 고정 (틀고정)**: 상단 긴급 기준 데이터 고정, 하단 총 결산/집계 요약행 고정
* **행 높이 제어**: 고정 행 높이 및 셀 내용에 맞춘 자동 행 높이 계산
* **실시간 데이터 동기화**: 행 추가/삭제/값 변경 시 변경 셀만 국소 재렌더링

### ③ 셀 렌더러 및 시각화
* **커스텀 셀 렌더러**: 상태 뱃지, 아이콘, 버튼 렌더링
* **인셀 차트 위젯**: 꺾은선 스파크라인, 목표 달성률 진행 바, 위험도 히트맵
* **데이터 서식(Format)**: 숫자 천단위 콤마, 통화 표기, 백분율, 날짜/시간 포맷터 자동 적용
* **빈 값 처리**: 결측치 대체 텍스트(`-`) 표기

### ④ 편집 및 데이터 조작
* **인라인 셀 편집**: 텍스트, 숫자 스피너, 드롭다운 셀렉트, 날짜 피커 에디터
* **범위 선택**: 마우스 드래그를 통한 직사각형 다중 셀 블록 선택
* **클립보드 연동**: 선택 영역 `Ctrl+C` 복사, 외부 스프레드시트 데이터 `Ctrl+V` 붙여넣기
* **파일 내보내기**: 그리드 서식 및 다단 헤더가 유지된 XLSX 파일 다운로드

### ⑤ 정렬 및 계층 트리
* **다중 열 정렬**: 헤더 클릭 단일 정렬 및 Shift + 클릭 다중 컬럼 순차 정렬
* **트리 노드 제어**: 단계별 노드 접기/펼치기, 전체 노드 일괄 토글
* **계층 데이터 탐색**: 상위 노드 접힘 상태에서도 하위 데이터 무결성 유지

## 5. 제안서 및 슬라이드 활용 가이드

* **고객 보고용 핵심 메시지**:
  1. **초고속 성능**: 100만 건 이상의 대용량 데이터도 지연 없는 가상 스크롤로 완벽 구동
  2. **업무 생산성**: 상·하·좌·우 4방향 틀고정과 엑셀 호환 키보드/클립보드 조작으로 실무 피로도 최소화
  3. **시각적 인사이트**: 셀 내부 미니 차트와 히트맵으로 별도 팝업 없이 즉각적인 데이터 파악
  4. **엔터프라이즈 완성도**: 1px 초정밀 선명도와 다중 테마(라이트/다크/스틸블루)로 고급 업무 환경 구축
