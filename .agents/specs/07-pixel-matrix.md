# 화면 07: 픽셀 도트 매트릭스 & 전광판 관제 (Pixel Matrix Showcase)

## 1. 개요 및 목적
* **목적**: 타키온(Tachyon) 그리드의 극단적인 Canvas 2D 고속 렌더링 성능과 셀 제어 역량을 증명하기 위한 파격적인 인터랙티브 쇼케이스 화면입니다.
* **핵심 콘셉트**: 그리드의 각 셀을 1개의 정밀 LED 도트(16px × 16px)로 매핑하여, 3,840개 셀을 60 FPS로 실시간 연산 및 렌더링합니다.
* **실무 활용 분야**: 반도체 팹 웨이퍼 맵 결함 검사, 데이터센터 서버 랙 인프라 히트맵, 금융 거래소 티커 전광판, 대형 레이더 관제 센터.

---

## 2. 그리드 및 매트릭스 규격

| 항목 | 규격 및 설정값 | 비고 |
| :--- | :--- | :--- |
| **컬럼 구성** | 64개 컬럼 (`c0` ~ `c63`) | 각 컬럼 폭 16px 고정 |
| **행(Row) 구성** | 60개 행 (`0` ~ `59`) | 각 행 높이 16px 고정 |
| **총 픽셀 셀 수** | **3,840개 셀 (64열 × 60행)** | 화면 세로/가로 균형감 있는 1:1 정밀 도트 |
| **셀 렌더러** | `CanvasPixelRenderer` | Canvas 2D 기반 LED 도트, 네온 글로우, 코어 하이라이트 |
| **목표 성능** | **60 FPS 유지 / 프레임당 0.1~0.2ms 소요** | 자바스크립트/브라우저 스레드 부하 1.5% 미만 |

---

## 3. 4대 인터랙티브 애니메이션 모드

1. 🛰️ **360° 회전 레이더 스캐너 (Radar Sweep & Blips) [기본 모드]**
   - **중심축**: $(x=32, y=30)$, 최대 탐지 반경 28칸
   - **동심원 눈금 링**: 7칸, 14칸, 21칸 간격의 4중 네온 그린 링 및 십자선
   - **스위프 잔상(Sweep Tail)**: 360도 회전 빔 뒤로 40도 폭의 네온 시안 잔상 페이드아웃
   - **타깃 블립(Target Blips)**: 8대의 미확인 타깃이 레이더 통과 시 네온 레드(🚨)/앰버 도트로 번쩍이며 실시간 탐지

2. 📺 **LED 전광판 티커 (LED Marquee Board)**
   - 오프스크린 캔버스 텍스트 비트맵 엔진 (폰트 크기 34px, 높이 48px)
   - 60행 중앙에 `"TACHYON CANVAS GRID 60 FPS ULTRA FAST 🚀"` 텍스트 무한 수평 스크롤
   - 상단 툴바에서 텍스트 자유 입력 및 실시간 반영

3. 🌊 **반도체 웨이퍼 파동 (Wafer Defect Ripple)**
   - 중심 $(32, 30)$을 기준으로 가로세로 1:1 동심원 사인(Sine) 파동 확산
   - 네온 시안, 에메랄드, 앰버 컬러 스펙트럼 맵핑

4. 🧬 **생명 게임 (Conway's Game of Life)**
   - 3,840개 셀에서 동작하는 실시간 셀룰러 오토마타 시뮬레이션

---

## 4. 완전 자동 순환 쇼케이스 (Auto-Cycle Demo)

* **시퀀스**: 레이더 ➡️ 전광판 ➡️ 웨이퍼 ➡️ 생명 게임 무한 순환
* **주기**: **7초 간격** 자동 전환
* **UI**: 툴바 내 `[🔄 자동 순환: ON/OFF]` 토글, `다음 모드 전환까지: N초` 카운트다운, 하단 2px 슬림 에메랄드 프로그레스 바 실시간 연출.
