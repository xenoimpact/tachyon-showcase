# 화면 6 스펙: 실시간 데이터 갱신 (초고속 성능)

## 1. 개요 및 목적
* **화면 ID**: `realtime` / 화면 번호 `06`
* **화면명**: `실시간 데이터 갱신 (초고속 성능)`
* **목적**: 스마트 팩토리 2,000대 공정 설비와 50개 IoT 센서 계측 데이터(총 100,000개 셀)가 초당 수십~수백 회 실시간 틱(Tick) 갱신되는 극한의 부하 환경에서도 60 FPS 무감속 가상화 스크롤과 부드러운 반응성을 시연합니다.
* **제안 슬라이드 매핑**: [슬라이드 6] 극한의 실시간 대용량 렌더링과 엔터프라이즈 성능 검증

## 4. 상단 KPI 대시보드 및 컨트롤러

### 1) 상단 통계 알약 (Stat Pills)
* **총 관리 설비**: `2,000대` (2,000개 행)
* **실시간 총 셀 수**: `100,000개` (2,000행 × 50열)
* **초당 데이터 갱신량**: `⚡ 60 셀/초` (실시간 변동)
* **렌더링 프레임율**: `🟢 60 FPS (지연 0ms)`

### 2) 우측 액션 툴바 컨트롤러
* **스트리밍 토글 버튼**: `실시간 스트리밍 중(ON)` ↔ `일시 정지(PAUSE)`
* **갱신 주기 세그먼트**: `초당 20셀 (안정)` / `초당 60셀 (표준)` / `초당 150셀 (스트레스)`
* **플래시 효과 토글**: 수치 변경 시 0.2초간 부드러운 잔상 하이라이트(상승: 레드 / 하강: 블루) 토글
* **Excel 내보내기**: 100,000개 전체 셀 데이터를 고속 Web Worker로 즉시 다운로드

## 5. 핵심 시연 포인트 (Key Demo Highlights)
1. **압도적인 고밀도 셀 뷰포트**: 한 화면에 600~800개의 셀이 노출되는 상황에서도 렌더링 지연이 전혀 없음.
2. **실시간 셀 단위 국소 갱신(Cell-level Tick)**: 전체 행이나 그리드 전체를 다시 그리지 않고 오직 변경된 셀 DOM만 즉각 업데이트하여 CPU/메모리 부하 0% 수렴.
3. **무감속 초고속 가상 스크롤**: 초당 수백 번 데이터가 변하는 와중에도 상하좌우 스크롤이 60 FPS로 매끄럽게 유지됨.
