# 데모 컨테이너 공통 스펙 (Demo Container Specification)

## 1. 개요 및 목적
* **문서 ID**: `specs/00-demo-container`
* **목적**: `tachyon-showcase`의 모든 화면(화면 1 ~ 화면 5)이 일관된 엔터프라이즈 UX, 모던한 시각적 완성도, 통일된 제어 인터페이스를 제공하도록 표준 데모 컨테이너 레이아웃과 그리드 테마 전환 규격을 정의합니다.
* **적용 대상**:
  - 화면 01: 기본 그리드 (Basic Grid)
  - 화면 02: 계층형 트리 그리드 (Tree Grid)
  - 화면 03: 대용량 가상 스크롤 (Virtual Scroll)
  - 화면 04: 엑셀형 셀 에디터 (Cell Editor)
  - 화면 05: 셀 시각화 (Cell Visualization)
  - 향후 확장될 React, Svelte 쇼케이스 패키지

---

## 2. 레이아웃 구조

데모 컨테이너는 시각적으로 명확히 분리된 **Header Card**와 **Grid Card** 2단 구조로 구성됩니다.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ DemoContainer                                                               │
│ ┌─────────────────────────────────────────────────────────────────────────┐ │
│ │ Header Card (demo-header-card)                                          │ │
│ │  ┌─ Tags (화면 번호, 핵심 기능 태그) ─────────────────────────────────┐ │ │
│ │  │ [화면 1] [2단 다단 헤더] [좌측 열 고정] [상태 배지]                 │ │ │
│ │  └────────────────────────────────────────────────────────────────────┘ │ │
│ │  ┌─ Title & Description ──────────────────────────────────────────────┐ │ │
│ │  │ 기본 그리드 (다단 헤더 & 열 고정)                                   │ │ │
│ │  │ 복잡한 엔터프라이즈 품의 및 주문 데이터를 직관적으로 구조화...     │ │ │
│ │  └────────────────────────────────────────────────────────────────────┘ │ │
│ │  ┌─ Control Toolbar (demo-actions) ───────────────────────────────────┐ │ │
│ │  │ [🎨 테마: Light | Dark | Steel Blue]  [통계 알약]  [액션 버튼 세트]│ │ │
│ │  └────────────────────────────────────────────────────────────────────┘ │ │
│ └─────────────────────────────────────────────────────────────────────────┘ │
│ ┌─────────────────────────────────────────────────────────────────────────┐ │
│ │ Grid Card (grid-card)                                                   │ │
│ │  ┌───────────────────────────────────────────────────────────────────┐  │ │
│ │  │                                                                   │  │ │
│ │  │               타키온 그리드 인스턴스 (TachyonGrid)                │  │ │
│ │  │                                                                   │  │ │
│ │  └───────────────────────────────────────────────────────────────────┘  │ │
│ └─────────────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 1) Header Card (`demo-header-card`)
* **배지 태그 (`demo-tags`)**:
  - 화면 식별자 배지 (예: `화면 1`, `화면 2`)
  - 핵심 기술 키워드 배지 (예: `가상 스크롤`, `Canvas 하이브리드`, `인라인 편집`)
* **헤더 정보 (`demo-info`)**:
  - 데모 제목 (`demo-title`): 20px, 볼드, 모던 타이포그래피
  - 데모 설명 (`demo-desc`): 비즈니스 가치와 시연 포인트를 고객 친화적 언어로 요약
* **컨트롤 툴바 (`demo-actions`)**:
  - **테마 선택기 (`theme-selector`)**: 전역/화면별 그리드 테마 즉시 전환 (Light / Dark / Steel Blue)
  - **통계 알약 (`stat-pill`)**: 데이터 건수, 합계 금액, 로딩 속도 등 실시간 메트릭
  - **액션 버튼 그룹 (`action-buttons`)**: 틀 고정 토글, 데이터 재생성, Excel 다운로드 등

### 2) Grid Card (`grid-card`)
* 고해상도 Canvas 및 DOM 하이브리드 렌더러가 장착되는 메인 영역
* 모던 라운딩(`12px`), 섬세한 카드 보더, 미세 그림자(`box-shadow`) 적용
* 테마 전환 시 그리드 테두리 및 배경색과 자연스럽게 동기화

## 3. 그리드 테마 시스템 규격

타키온 내장 `theme` API(`tachyon.theme.add`) 및 CSS 스타일링을 유기적으로 결합하여 3가지 테마를 제공합니다.

| 테마 ID | 명칭 | 시각적 특징 | 주요 사용 목적 |
| :--- | :--- | :--- | :--- |
| `default` | **Enterprise Light** | 화이트 배경, 밝은 회색 테두리, 슬레이트 폰트 | 기본 업무용, 전형적인 ERP/그룹웨어 환경 |
| `dark` | **Modern Dark** | 딥 네이비(#0f172a), 슬레이트 보더(#334155), 라이트 그레이 폰트 | 관제 센터, 개발자 친화적 모던 다크 모드 |
| `steel-blue` | **Steel Blue** | 짙은 인더스트리얼 블루(#0f2438), 스틸 하이라이트(#38bdf8) | 현대제철 등 제조업/MES 공정 관제 대시보드 |

### 1) 테마 등록 구조 (Config)
```typescript
// packages/vue/src/config/tachyon/themes/
tachyon.theme.add('dark', {
    css: 'theme-dark',
    canvasStyle: {
        color: '#e2e8f0',
        cellOverColor: '#1e293b',
        cellSelectionColor: '#334155',
        rowLine: { color: 'rgba(255, 255, 255, 0.08)' },
        columnLine: { color: 'rgba(255, 255, 255, 0.08)' },
        // ...
    }
});
```

### 2) CSS 동기화 규칙
* 그리드 루트 엘리먼트에 테마별 CSS 클래스(`theme-dark`, `theme-steel-blue`)가 자동 주입됩니다.
* 헤더 배경(`header-cell`), 그룹 헤더(`tachyon-group-header`), 테두리(`border`)는 CSS 클래스를 통해 정밀 제어합니다.

## 4. 공통 컴포넌트 인터페이스 (`DemoContainer.vue`)

### Props
```typescript
interface DemoContainerProps {
    /** 화면 번호 배지 텍스트 (예: '화면 1') */
    badge?: string;
    /** 기능 키워드 태그 목록 */
    tags?: string[];
    /** 화면 제목 */
    title: string;
    /** 화면 상세 설명 */
    description: string;
    /** 초기 적용 테마 ('default' | 'dark' | 'steel-blue') */
    defaultTheme?: string;
}
```

### Slots
* `stats`: 데이터 건수, 합계금액 등 통계 알약 표시 영역
* `actions`: 화면별 특화 기능 버튼 (틀 고정, 편집 모드 토글 등)
* `default`: 타키온 그리드 인스턴스 (`TachyonGrid`) 및 부가 시각화 요소

### Emits
* `theme-change(theme: string)`: 테마 변경 시 부모 컴포넌트로 전달하여 그리드 바인딩 갱신
