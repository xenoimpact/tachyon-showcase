# 화면 4 스펙: 인라인 셀 편집 및 엑셀 입출력 (Cell Editor & Excel I/O)

## 1. 개요 및 목적
* **화면 ID**: `editor` / 화면 번호 `04`
* **목적**: 마우스와 키보드(방향키, Tab, F2, Enter)를 통한 신속한 엔터프라이즈 인라인 데이터 편집과 데이터 타입별 전용 에디터(텍스트, 숫자 콤마, 날짜 캘린더, 드롭다운 셀렉터), 클립보드 복사/붙여넣기 및 엑셀 입출력을 시연합니다.
* **제안 슬라이드 매핑**: [슬라이드 4] 키보드 중심의 빠른 데이터 조작, [슬라이드 7] 정렬과 필터

## 4. 핵심 시연 포인트 및 인터랙션 시나리오
1. **키보드 중심 고속 데이터 조작**:
   * 셀 더블클릭 또는 `F2` 키로 인라인 편집 진입.
   * `Enter` 또는 `Tab` 키로 수정 확정 후 다음 행/열로 자연스럽게 포커스 이동.
   * `Esc` 키 입력 시 수정 취소 및 기존 값 복원.
2. **실시간 비즈니스 수식 연동**:
   * '수량' 또는 '단가' 셀 수정 즉시 연관된 '공급가액', '부가세', '합계금액'이 실시간으로 동기화 재계산.
3. **클립보드 다중 복사 및 붙여넣기**:
   * 그리드 내 복수 셀 드래그 선택 후 `Ctrl+C` 복사.
   * 엑셀에서 복사한 다중 행/열 텍스트를 그리드에 `Ctrl+V`로 즉시 일괄 반영.
4. **백그라운드 엑셀 입출력**:
   * 수정된 최신 그리드 데이터를 Web Worker를 통해 `.xlsx` 파일로 고속 내보내기.
